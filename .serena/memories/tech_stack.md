# Technology Stack

## Language
- Python >=3.11

## Core Dependencies
- numpy — array operations, linear algebra
- scipy — sparse matrices, eigenvalue solvers, LU factorization
- matplotlib — visualization
- sympy — symbolic math
- pyyaml — configuration parsing

## Dev Dependencies
- pytest-cov — test coverage
- hatchling — build system

- PyTorch — neural networks (encoder/decoder, INR)
- GPyTorch or BoTorch — Gaussian Process integration
- scikit-learn — metrics, cross-validation
